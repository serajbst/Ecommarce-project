# AshrafChak E-Commerce

A full-stack e-commerce platform designed to make online shopping convenient for customers in Ashraf Chak and nearby areas of Simri Bakhtiyarpur, Bihar.

## Tech Stack

**Frontend**
- React.js
- Vite
- Tailwind CSS
- React Router

**Backend**
- PHP
- MySQL
- REST API architecture

## Features

- Responsive, mobile-friendly shopping interface
- Product listing and category browsing
- Product details
- Shopping cart and checkout
- Order placement and order management
- Admin dashboard
- Product and inventory management
- Stock adjustment and inventory transactions
- Backend API integration
- Database-driven product and order operations
- Authentication and protected admin functionality

## Admin Dashboard

The admin dashboard provides tools for managing products, inventory, and order-related operations.

## Project Purpose

AshrafChak E-Commerce aims to bring everyday shopping online for the local community, with a focus on electrical products, electronics, mobile accessories, household items, and other available products.

## Installation

1. Clone the repository.
2. Install frontend dependencies using `npm install`.
3. Configure the PHP backend and MySQL database.
4. Set the correct API base URL for your environment.
5. Configure the database connection securely.
6. Start the frontend development server using `npm run dev`.
7. Build the production frontend using `npm run build`.

## Security

- Keep database credentials and API secrets out of version control.
- Use server-side validation and authorization.
- Use prepared statements for database operations.
- Configure production environment settings before deployment.
